# progettoCG

Corso: Computer Grafica  
Università: Università di Pisa  
Anno Accademico: 2025/2026

Il progetto è stato sviluppato in C++ usando OpenGL 4.6 e VisualStudio 2022

## Controlli
L'applicazione supporta diverse modalità di visualizzazione. È possibile navigare liberamente la scena o impersonare uno dei "cameraman" disposti a bordo pista.

* [ W ] [ A ] [ S ] [ D ]: Movimento della telecamera libera.
* Mouse (Click sx + Drag): Rotazione della visuale.
* Rotellina Mouse: Zoom in/out.
* [ C ]: Attiva la modalità "Cameraman". Premerlo ripetutamente per ciclare tra le varie telecamere a bordo pista e la telecamera principale.
* [ R ]: resetta la telecamera princiaple nella posizione di partenza, anche se si è in modalità cameraman.
* [ T ]: Resetta lo zoom della trackball.
* [ ESC ]: Chiudi l'applicazione.
